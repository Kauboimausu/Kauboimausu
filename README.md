### What I'm working on

- **Biomedical signal processing at IIMAS-UNAM:** processing surface EMG (sEMG) recordings from the NinaPro database and building exploratory classification models for hand-gesture recognition.
- **Chinese OCR, end to end:** a CNN with transfer learning for handwritten/printed character recognition, growing into text detection, a FastAPI service, Docker and cloud deployment.
- **A RAG project:** a RAG that answers questions about sEMG signals for classification of hand-gesture technologies based on a corpus of license-appropriate articles.
- **Currently learning:** SQL, AWS, Docker, Power BI.
